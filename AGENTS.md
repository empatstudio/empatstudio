# empat.studio projekto darbo taisyklės

Kuriant ar keičiant šią svetainę, prieš dizaino ar UI darbus perskaityti ir laikytis `BRAND_GUIDELINES.md`.

- Brandbooko faktus laikyti autoritetingais; web adaptacijas aiškiai atskirti nuo originalių taisyklių.
- Naudoti tik patvirtintą empat.studio spalvų, tipografijos, logotipo ir organinių formų sistemą.
- Logotipo neperpiešti ir neatkurti paprastu HTML tekstu; naudoti oficialų assetą.
- Naujas spalvas, šriftus ar vizualinę kryptį įvesti tik gavus aiškų savininko patvirtinimą.
- Išlaikyti prieinamumą, kontrastą, responsive elgseną ir `prefers-reduced-motion` palaikymą.
